Reading the names

Neural DSP renames real brands. The common prefixes:

Suffixes & tags
(M)
Mono version, lighter on DSP.
(ST)
Stereo version, for stereo rigs or wide time effects.
(S/C)
Sidechain version: a second input (another row or input) controls it, e.g. ducking or keyed gating.
Patch
Both input channels jumpered together, the classic "jumped" vintage Marshall/Fender trick for a fatter, hotter tone.
Lite
IR loader without the built-in room reverb, so it uses less DSP.
New 4.1
Added in CorOS 4.1.0.
Plugin
Only loads if you own that Neural DSP plugin licence, linked to your account.
Also new in 4.1.0

Device Presets: save and recall settings for any single amp or effect, with 2,000+ factory Device Presets from Neural DSP.

Archetype X plugins on the unit: John Mayer, Petrucci, Misha Mansoor, Rabea and Tim Henson X add 70+ amps, cabs and effects if you own the licence.

Changes: Mono Synth is now called Overlord Synth. Doubler and Plugin Doubler gain an INPUT three-way switch. Plugin Blend and Transparent Blend gain a BLEND LEVEL knob.
